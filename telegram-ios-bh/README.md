# 🚀 Telegram + BHTelegram (Anti-Delete & Ghost Mode for iOS)

Сборка модифицированного Telegram для iOS с возможностью **сохранять удаленные сообщения**, просматривать историю изменений сообщений, скрытным режимом (Ghost Mode) и сохранением таймерных медиа.

Проект подготовлен для быстрой облачной сборки через **GitHub Actions** (2-3 минуты) и установки через **Sideloadly** на бесплатном Apple ID.

---

## 🔥 Что умеет клиент (AyuGram-фичи на iOS)
* **Анти-удаление сообщений:** Удаленные сообщения остаются в чате с пометкой (значком корзины).
* **История редактирования:** Просмотр оригинального текста сообщений до редактирования.
* **Сохранение самоуничтожающихся медиа:** Таймерные фото и видео можно сохранять в галерею.
* **Ghost Mode (Невидимка):**
  * Чтение сообщений без отправки статуса «Прочитано».
  * Скрытие статуса набора текста («печатает...»).
  * Скрытие статуса «В сети».
* **Блокировка рекламы** (Telegram Ads) и скачивание историй.

## ⚡ Способ 1: Собрать свой IPA через GitHub Actions (рекомендуется)

1. Создай новый **публичный или приватный репозиторий** на [GitHub](https://github.com/new).
2. Загрузи в него папку `.github/workflows/build-ipa.yml`.
3. Перейди во вкладку **Actions** в твоем репозитории.
4. В левом меню выбери воркфлоу **`Build Telegram + BHTelegram (Sideloadly Ready)`**.
5. Нажми кнопку **Run workflow** -> подтверди запуск.
6. Сборка займет **~2 минуты**.
7. Когда воркфлоу завершится (зеленая галочка), зайди внутрь сборки и в блоке **Artifacts** скачай готовый архив `Telegram_AyuBH_Sideloadly`.
8. Распакуй архив — внутри будет готовый файл `.ipa`.

## 📲 Установка через Sideloadly (Пошагово)

> [!IMPORTANT]
> На бесплатных аккаунтах Apple ID есть лимит: не более 10 App ID в неделю и 3 активных приложения.
> Официальный Telegram содержит 6+ расширений (виджеты, шэринг), из-за которых Sideloadly может выдавать ошибку. В нашем скрипте сборки расширения уже автоматически очищены для 100% совместимости с бесплатным Apple ID!

1. Скачай и запусти [Sideloadly](https://sideloadly.io/) на ПК.
2. Подключи iPhone кабелем к компьютеру и разблокируй экран (нажми «Доверять этому компьютеру», если появится запрос).
3. Перетащи скачанный файл `Telegram_AyuBH_Sideloadly.ipa` в окно Sideloadly.
4. В поле **Apple ID** введи свой логин iCloud/Apple ID.
5. Нажми кнопку **Start** и при необходимости введи пароль от Apple ID / код 2FA.
6. Дождись надписи **Done!**. Приложение появится на рабочем столе айфона.

### Первый запуск на iOS:
* На iPhone перейди в: **Настройки -> Основные -> VPN и управление устройством**.
* В блоке «ПО разработчика» нажми на свой Apple ID и выбери **«Доверять»**.
* Если у тебя iOS 16+: перейди в **Настройки -> Конфиденциальность и безопасность -> Режим разработчика** и включи его (потребуется перезагрузка).

## ⚙️ Как включить сохранение удаленных сообщений

1. Открой установленный Telegram.
2. Перейди во вкладку **Настройки** (Settings).
3. Найди пункт **BHTelegram** (или **BH Settings**).
4. Активируй тумблеры:
   * **Keep Deleted Messages** (Сохранять удаленные сообщения)
   * **Keep Edited Messages** (Сохранять отредактированные)
   * **Disappearing Media** (Сохранение таймерных фото)
   * **Ghost Mode** (по желанию).
